# Eksport normalized expansion i następne osobne typy

NORMALIZED_EXPANSION_CERTIFICATE eksportuje dla Emitted/same-STATIC-decode
i legalnych allocations:
- actual successful internal load_skey continuation po RAW;
-1536 exact source stored widths w RAW leaf positions,16896 internal L
  i6144 basis words zachowane bitowo;
- mandatory stable-gate bridge, exact D_min/D_max, source sqrt54/div/scaling;
- stored sigma²∈(1.7763,575.9999), paired sigma²∈(2.3684,767.9999), word/value
  enclosures i literal positive finite dss≥actual last coefficient;
- structural3072 sigma uses, paired first/stored second per terminal leaf;
- explicit memory/pointer/return/type domains i mixed proof boundary.

All-P_key computational definedness ma osobny proof. All-P_key narrow stable
gate acceptance pozostaje OPEN_NOT_DISPROVED i nie jest nową przesłanką P_key.
Główny emitted result go nie wymaga. Nie zmienia się K_seed[E]/p_K.

## INITIAL_TARGETS — następny odrębny typ

```
forall E,sk,pk,p,c,memory,
 Emitted(E,sk,pk) -> SameSTATICDecode(sk)=p ->
 NormalizedExpansionCertificate(p,memory) -> LegalTargetBuffers(memory,c) ->
 DefinedTerminating(actual source FFT3(c),basis products,inverse(q),targets)
 and ExactSourceTargetWords and RequiredInitialTargetDomainsAndErrors
 and NormalizedKeyPreserved.
```

Należy związać physical frequency/order, znak/normalizację1/q i source
operations; nie zastępować ich idealnym target formula bez bindingu.

## ORDERED_REACH → NumericCenter — również OPEN

```
forall legal emitted/M0 signing prefixes (also norm-rejected attempts),
 at each actual ordered sampler call before floor/cast/residual(mu),
   NumericCenter(mu) and the required source input/memory conditions.
```

Nowy sigma certificate zapewnia width/dss domain tylko dla odpowiednich
source words; nie dowodzi wykonania wcześniejszego mu prefixu, PRNG/rejection
termination lub joint sampler law. Cumulative error/reach trzeba prowadzić
w rzeczywistej right-before-left kolejności, z fault/retry observations.
ZERO_SCALAR pozostaje lokalnym zero-aware consumerem. H1R/FFO/R5T/M7,
sampler-law/security reduction i całe Sign CT są osobnymi obowiązkami.
Na tym handoffie nie rozpoczęto targets lub Reach.
