# Zakres i freeze

scripts/scope.py wylicza wszystkie regularne pliki W poza root tmp/,bin/,cache/,
COMMANDS.log,executor.lock,OUTPUTS.sha256 oraz __pycache__/.olean/.ilean/.pyc.
Symlinki/escapes i member>32MiB są odrzucane. Source17 files i pełny bootstrap
są readonly/pinned; publiczne synthetic words,PMFs,rigorous Gaussian outputs,
native logs,failed routes,formal sources i certificates wchodzą w scope.
Nie ma keys,secrets,seeds,private extraction,credentials lub project binaries.

W jest trwałym ext4. Wszystkie HOME/TMP/cache/olean/bin/replaye pod W;
systemowy /tmp i tmpfs nie przechowują plików projektu. Marker-only readonly
inputs/hidden_originals służy do zasłaniania Dokumenty/stages w replayu.

COMMANDS.frozen.log i final_prefix.log zachowują completed prefixes z
bytes/count/hash receipts. Dynamiczny root COMMANDS tail nie jest authoritative.
Failed stdout/stderr/sources pozostają zachowane; clean final Lean logs są
oddzielnym audytem, nie filtrowaniem historii w celu uzyskania PASS.

Rehearsal anchor poprzedza samego siebie,fresh_replay,REPORT/RESULT/OUTPUTS.
Sealed artifacts/fresh_replay.json zawiera FRESH_REPLAY_PASS oraz niepuste
matches[{path,sha256}] rzeczywiście odtworzonych semantic outputs. Brak cyklu
hashy. Po OUTPUTS freeze zapis tylko do NOWEGO DEST pod tmp, pakiet RO.
Source/integration/owner flags dotyczą tego etapu; import/Git nie są wykonywane.
