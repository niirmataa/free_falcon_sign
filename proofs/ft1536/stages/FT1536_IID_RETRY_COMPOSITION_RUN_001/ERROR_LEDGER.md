# Ledger domen i kosztów

Ten etap nie wprowadza nowych floating-point approximations. Konsumuje
source-target/root/post domains i H6P complete-error bound1095 wraz z
conditional one-root p_outward; nie nalicza błędów ponownie jako independent
per-attempt events. Rachunek outer retry jest exact integer/rational.

- Probabilistic ideal-region envelope: stopped weighted pE[J], uniform16p,
  a także1-(1-p)^16 dzięki uniform CONDITIONAL hazard. Power-of-two2^-80.
- Checked/public coupling discrepancy: ten sam WholeRegionBad, nie drugi
  niezależny loss do dodania. Bad AND positive return jest inclusion event.
- Finite-resource ghost: complement of every-reached-root T<=49152,
  <2^-1020. Wspólny event dla wszystkich resource budgets, nie unia po
  każdej kolumnie tabeli. To odrębny interface do przyszłego PRNG hopu.
- No success denominator proved. Conditional-on-success bound bez niego
  może wynosić1; nie eksportujemy małej liczby jako conditional result.
- Real SHAKE/ChaCha loss, H2P-prefix termination, reference integer recovery,
  Sign→Verify/security/CT nie są liczbami0 — są OPEN i nie stanowią eta_pre.

Exact wartości, scope i źródła maszynowe są w ERROR_LEDGER.json,
