## Four separate error layers

1. Raw matrix versus reconstructed local source factor: new direct expansion
   retains source operation errors, imaginary/split defects i actual pivots.
   Loewner/pivot induction daje derived multiplicative comparison.
2. Stable positive algorithm versus exact positive pivots: monotonic/homogeneous
   functions i source factors(1±2^-40)^9, plus reciprocal factor(1±2U).
   Raw i stable leaves nie są bitowo identyczne.
3. Actual returned right residual versus exact source-L reconstruction:
   merges/CM/sub errors, actual terminal pairs already contain half defect.
   Nie liczymy terminal/sub errors ponownie ani nie resamplujemy repeated products.
4. Root update i left source splitting: source CM/add errors, mathematical
   coefficient norm transport, następnie jawny signal/history recurrence.
   Initial/updated frequency targets nie są utożsamiane ze scalar mu.
