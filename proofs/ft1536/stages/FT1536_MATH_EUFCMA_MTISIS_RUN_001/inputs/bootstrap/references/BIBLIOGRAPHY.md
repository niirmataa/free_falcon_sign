# Literatura wskazana przez właściciela — materiał pomocniczy

1. **A Closer Look at Falcon**,ePrint2024/1769.
   https://eprint.iacr.org/2024/1769
   Strona odczytana przez prowadzącego2026-09-23 podaje ostatnią rewizję
   2026-03-02,major revision of EUROCRYPT2026. Autorzy aktualnej strony:
   Pierre-Alain Fouque,Phillip Gajland,Hubert de Groote,Jonas Janneck,Eike Kiltz.
   Abstract wskazuje ordinary unforgeability vs multi-target inhomogeneous SIS
   i odrębny problem second-preimage dla strong unforgeability.
2. Thomas Prest,**Sharper Bounds in Lattice-Based Cryptography using the
   Rényi Divergence**,ePrint2017/480,ASIACRYPT2017.
   https://eprint.iacr.org/2017/480
   Strona podaje rewizję2017-09-07. Materiał o tailcut/relative-error bounds
   i zastosowaniach dywergencji Rényiego do samplerów.
