# Atrybucja

Projekt FT1536: Niirmata (`niirmataa`). Historyczny kod Falcon oraz jego
atrybucje Falcon Project / Thomas Pornin pozostają bez zmian. W tym zadaniu
nie kopiowano ani nie modyfikowano implementacji C; bootstrap zawiera jej
historyczne opisy i piny.

Dołączona source closure Lean, Mathlib i zależności zachowuje oryginalne
nagłówki, autorów oraz oznaczenia licencji. Pliki te są niezmienionymi
zależnościami, nie wynikiem autorstwa tego runu. Rewizje: TOOLCHAIN.json,
PREFLIGHT.json i inputs/bootstrap/TOOLCHAIN_PINS.json. Dostępne główne pliki
licencji znajdują się w dependency-licenses/.
