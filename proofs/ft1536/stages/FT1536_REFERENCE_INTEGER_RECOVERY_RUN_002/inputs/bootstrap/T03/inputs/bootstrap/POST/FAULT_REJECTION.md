# Fault, stutter, nonreturn i zakres caller

LEFT NumericCenter i scalar integer-domain proofs wykluczają source guard faults
forward dla wymaganych active legal histories. Po completed sampling wszystkie
wcześniejsze terminal calls wróciły normalnie. To konsumowana source przesłanka,
nie założenie, że caller final fault check naprawia wcześniejsze operacje.

Suffix1902–1934 nie odczytuje ani nie zmienia fault. Caller sprawdza go3374,
dopiero po całym do_sign. Nie udowadniamy arbitrary malformed callback/tape
faulted-tail safety. W takim rozszerzeniu powrót scalar0 nie ma normal residual
closeness; operational theorem tego nie konsumuje. Outside-domain nie staje się
nowym production abort, clippingiem lub key premise.

Rozróżnienie zdarzeń:
- normal completed call: source residuals i proven deterministic suffix;
- rejection stutter: brak caller store/return jeszcze;
- infinite inner rejection/byte source nonreturn: brak completed return,
  nie norm rejection, timeout source ani return0;
- norm rejection po completed suffix: następna outer attempt;
-16 completed outer rejections: source cap return0 na kolejnym guard;
- codec capacity failure: source0, możliwe partial body writes, header nietknięty;
- accepted M0 case: capacity failure wyklucza M03160<4096, exact bytes0xaa||body.

BadPrecast nie jest source fault flag ani rejection condition. Prawdopodobieństwo
tego joint event i całego source success/abort/nonreturn nie zostało oszacowane.
