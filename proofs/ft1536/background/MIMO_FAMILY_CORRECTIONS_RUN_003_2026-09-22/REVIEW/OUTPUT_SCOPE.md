# Scope of this maintainer archive

The author's43 SHA256SUMS-listed files and SHA256SUMS itself are retained
byte-for-byte at their original relative names. The author did not provide
the repository's REPORT/RESULT/INPUTS/OUTPUTS protocol. The maintainer adds
those archival records, README/REPLAY/OUTPUT_SCOPE, pinned input copies and
review evidence. The reviewed author's files are not rewritten to implement
the requested corrections.

OUTPUTS.sha256 seals all regular files in this container except itself.
INPUTS.sha256 records the read-only review snapshot, source bytes and reused
M0/L_V/RAW references. Cache, oleans, binaries and mutable job workspaces are
not outputs of this checkpoint. The research scripts and original compiled
PDF are retained as public research artifacts.

Status RESEARCH_REVIEW_CHANGES_REQUIRED is the maintainer's assessment,
not an original author declaration of a fully proved scheme. Selected checks
and negative findings retain their exact scope. replay=none records that no
single complete package replay was declared; command logs for the performed
scoped independent checks are retained.
