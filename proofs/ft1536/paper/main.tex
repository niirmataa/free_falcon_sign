\begin{abstract}
We present a formal security case for FT1536, a research signature
profile in the Falcon lineage with ternary secrets, in which every
mathematical statement is bound to pinned fragments of the
implementation it describes. The formal classical game admits a
conditional reduction from EUF-CMA to multi-target inhomogeneous
short-integer solution; a pointwise sampler comparison computes the
second-moment error $e=k^{32}-1<2^{-32}$ for the unconditioned attempt
shape, and $e<2^{-17}$ for the acceptance-conditioned shape, which of
the two describes the realized signer being an open source-binding
obligation. A separate computational theorem bounds a stream-driven
public simulation through an admitted class of randomized tests and an
explicit cost certificate. Negative results are stated as theorems:
bulk control does not control the norm-rejected tail, a total-mass
sandwich does not give pointwise control, additive accuracy alone does
not yield the machine stage, and the statistical route for the modeled
finite-state generator is closed. The verification process itself found
defects, in vendored C code and in the formal models built to describe
it. Two interfaces remain in flight: the honest-signing hop and the law
bindings; the bridge from the real signer to the games is not closed.
We report security as two numbers per profile --- model-dependent
lattice diagnostics and symmetric search ceilings --- and account the
system level as their minimum. This draft claims neither end-to-end
implementation security nor a QROM reduction; all unresolved interfaces
are listed in the body.\src{C01,C04,C06,C09,C10,C12,C14,C15,C20}
\end{abstract}
