\begin{abstract}
We describe a formal reduction framework for FT1536, a research signature
profile derived from Falcon with ternary secrets. The formal classical
game has a conditional EUF-CMA to multi-target inhomogeneous short-integer
solution reduction. A pointwise sampler-comparison framework computes
an error parameter $e=k^{32}-1<2^{-32}$ for its unconditioned attempt
shape; the corresponding acceptance-conditioned framework gives
$e<2^{-17}$. These bounds require the stated law and weight interfaces.
A separate computational theorem bounds a stream-driven public
simulation using an admitted class of randomized tests and an explicit
cost certificate. We present counterexamples to insufficient sampler
arguments and defects found during source binding. The connection from
the real signer to these games remains in flight. This draft makes no
end-to-end implementation-security or QROM claim; its unresolved
interfaces are listed in the body.\src{C01,C04,C06,C09}
\end{abstract}
