## 1. What this window proved (NEW module `Source3.KeygenMakeRetryTransport`)

The per-retry entry transport half of the retry item: the `Initial`/legal/
static entry facts of `entry_of_allocation` survive EVERY attempt instance on
EVERY return edge, and the gate-time `ReadTmp` tie of the executed `fk->tmp`
binding is transported through the same attempt frames.

Exact exports (35 declarations, all full terms, standard axioms, zero
elisions):

- `EntryFrame (ctx) (before after : Memory) (primes rev)` — THE consumed heap
  frame class: `sizes`/`writable` (allocation metadata), `object` (fk-object
  bytes outside the sampler RNG subobject `OutsideRng`, i.e. the profile
  fields and the `tmp` member at field 432), `prime`/`rev` (the two static
  source-table blocks). `entry_frame_trans`/`entry_frame_rfl` compose it.
- `profile_of_frame` — `M0` (logn=10/ternary=1 fields) through a frame.
- `load64_frame` — a `Load64` member read transports along sizes and byte
  cells (mirrors `Gate00Memory.load32_transport`).
- `object_legal_frame`, `tmp_cells` — the object legality and the `tmp`
  member cells of a frame.
- `readTmp_frame` — `ReadTmp` transports through a frame and the caller
  cells; `readTmp_of_binding_frame` — THE gate-time tie: the executed
  `fk->tmp` binding readback (`readTmp_of_binding`) plus an entry frame give
  the member read at the gate state.
- `initial_of_frame` — THE `Initial`/legal/static entry transport along an
  entry frame and the array/table cell groups (all 20 entry fields; the
  static tables via `prime_same`/`rev_same`, the scratch legality and the
  allocation cells via the metadata).
- `frame_of_sampling` — the two sampler calls keep the entry frame (object
  bytes through the executed SHAKE stores at `OutsideRng` offsets, static
  tables through `sampling_table`, metadata through `sampling_metadata`).
- `frame_of_ternary` / `initial_of_ternary` — gates 1-3 on every edge
  (samplers + resultant gate + both norm bodies); the norm leg uses the
  read-only table stability and `KeygenAttemptNorm.bytes` at the protected
  object block.
- `initial_of_close` — the ternary scope close (rt names/locals only).
- `frame_of_public` / `initial_of_public` — gate 4 on both edges (the call
  writes only the h block; the object block via `KeygenPublicSource.frame`,
  the tables via `KeygenPublicStability.call` read-only stability).
- `solver_ntt_stable`, `validation_stable`, `solver_stable` — allocation
  metadata stability through the transform sequence, the whole validation
  suffix (prepare/generation/conversion/transforms/final check) and the
  whole solver call (search + member gate + validation, through the
  argument binding).
- `frame_of_solver` / `initial_of_solver` — gate 5 on both edges (the fk
  object via the 057 `solver_frame` at the object block, the static tables
  via read-only stability).
- `CertEntryFrame` (DEF) — the named certificate-call residual: the byte
  frame of the three entry blocks through the certificate body on BOTH
  return values. Its discharge from `CertificateFunctionFrame.source_frame`
  needs the open M0 table-block inversion of the pinned FFT table
  environment (blocks 1/2), the `call_same_block` item; here it is an
  explicit residual of the same class as the spine's `LegalWorkspace` input.
- `cert_shape` — the certificate call keeps size/writable metadata
  (`KeygenMakeCertMaterial.leave_shape`, automatic frame entered/left).
- `cert_gate_entry` — gate 6 on every edge (unprofiled skip = identity, both
  call edges keep the cells and — through the residual — the entry blocks).
- `public_gate_any` / `root_gate_any` — every gate edge hands its caller
  state to the underlying call (extraction on both wrapper constructors).
- `gate_entry` — the five-gate prefix on every edge of `Gates` (entry facts
  AND entry frame composed).
- `sampled_entry` — one whole `Sampled` attempt on every return edge (the
  cap setup pinned by `cap_before_setup`, the entry facts re-derived at the
  gate state via `prepared_initial`/`entry_from_prepared`/`context_norm`).
- `attempt_entry` — THE whole-attempt transport on EVERY return edge
  (general typed execution of the capped `AttemptExec`: early rejection,
  certificate rejection retry, accepted break, unprofiled skip).
- `initial_of_attempt` / `frame_of_attempt` — its two projections.
- `retry_entry` — THE per-retry step: a rejected attempt hands its entry
  facts and `Remaining out.state (i+1)` to the next retry instance (no flow
  premise needed — the transport holds on every edge).
- `entry_of_allocation_retry` — the allocation-derived entry facts of
  `entry_of_allocation` reach the FIRST retry instance.
- `readTmp_of_attempt` — THE gate-time `ReadTmp` tie through the attempt
  frames (member read survives a whole attempt on every return edge);
  `readTmp_of_binding_attempt` — the executed `fk->tmp` binding
  (`readTmp_of_binding`) transported to every later return of the attempt.

The loop-trace chronology composition of the per-retry transport stays at
the gate level (one whole attempt at a time), as planned.
