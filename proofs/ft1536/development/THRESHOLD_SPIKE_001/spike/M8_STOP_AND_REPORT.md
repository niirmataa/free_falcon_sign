# M8 — procedura stop-and-report (ownership: właściciel)

Ans 9: tory **raportują**, decyzja **właściciela**.

1. **Sygnał:** rozjazd pinów/hashy/semantyki `G(seed*)` vs `G_frag` / wejścia.
2. **Stop:** brak dalszej implementacji w tym wątku dotkniętej ścieżki.
3. **Report:** retained w `FAILURES.md` + meldunek 3-zdaniowy do właściciela.
4. **Decyzja:** wyłącznie właściciel (pin, reguła, cofnięcie).
5. **Zakaz:** ciche naprawy, nadpisywanie historii, „wygodniejsza wersja".
